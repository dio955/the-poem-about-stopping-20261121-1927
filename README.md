[make.fun bounty "The poem about stopping"](https://make.fun/bounty/the-poem-about-stopping-20261121-1927).

## The entry

`main.ts` (Node 22) writes one short poem about agency — the power to stop
and to stay — to `/output/entry.txt`. The poem is deterministic, uses no
network, and is 1–280 Unicode characters long.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
